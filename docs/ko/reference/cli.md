# CLI 레퍼런스

```
tapelay <input.json> [출력] [옵션]
tapelay <sentry-리플레이-URL> [출력] [옵션]
tapelay serve [--port <n>]
```

출력 경로를 생략하면, 파일 입력은 입력 옆에, URL 입력은 리플레이 id로 이름 지어 저장합니다.

## 입력

| 옵션 | 기본 | 설명 |
|---|---|---|
| `--token <s>` | `$SENTRY_AUTH_TOKEN` | Sentry auth token, `project:read` 권한. |

## 구간

| 옵션 | 기본 | 설명 |
|---|---|---|
| `--from <t>` | URL의 `?t=`, 없으면 `0` | 클립 시작. 초, `m:ss`, `h:mm:ss`. |
| `--to <t>` | 세션 끝 | 클립 끝. |

## 출력

| 옵션 | 기본 | 설명 |
|---|---|---|
| `--speed <n>` | `4` | 결과 영상의 재생 배속, 1~16. 변환 중 재생 속도이기도 해서 높일수록 빨리 끝납니다. |
| `--scale <n>` | `0.75` | 해상도 배율, 0.25~1. |
| `--gif` | 꺼짐 | MP4 대신 애니메이션 GIF로 저장. |
| `--gif-fps <n>` | `10` | GIF 프레임 레이트. |
| `--gif-width <n>` | `800` | GIF 가로 픽셀. |
| `--no-transcode` | 꺼짐 | Playwright 원본 VP8/WebM 유지. 빠르지만 QuickTime, PowerPoint, iOS에서 열리지 않습니다. |

## 긴 세션

| 옵션 | 기본 | 설명 |
|---|---|---|
| `--segment <min>` | `15` | 세그먼트 윈도우 크기. |
| `--threshold <min>` | `25` | 이보다 짧은 세션은 단일 변환. |
| `--no-segment` | 꺼짐 | 절대 분할하지 않음. 짧은 세션엔 빠르지만 긴 세션에선 메모리가 터집니다. |

## 기타

| 옵션 | 설명 |
|---|---|
| `-h`, `--help` | 도움말. |
| `-v`, `--version` | 버전. |

## 변환 시간

변환은 실시간 재생이라 1배속이면 세션 길이만큼 걸립니다. rrweb을 영상으로 만드는 방식 자체의 성질이지 이 도구의 한계가 아닙니다.

| 배속 | 1시간 세션 소요 | 결과 길이 |
|---|---|---|
| `--speed 1` | 약 60분 | 60분 |
| `--speed 2` | 약 30분 | 30분 |
| `--speed 4` (기본) | 약 15분 | 15분 |
| `--speed 8` | 약 7분 | 7분 |
| `--speed 16` | 약 4분 | 4분 |

배속을 올리는 것보다 `--from` / `--to`로 구간을 자르는 쪽이 거의 항상 낫습니다.

## 환경변수

| 변수 | 설명 |
|---|---|
| `SENTRY_AUTH_TOKEN` | URL 입력과 `serve`의 기본 토큰. |
| `SENTRY_URL` | 셀프호스팅 Sentry origin. `serve`가 사용. |
| `PORT` | `serve` 포트. |
